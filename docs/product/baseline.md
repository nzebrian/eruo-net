# Locked EruoNet Product Baseline

This document records the locked EruoNet Cloud baseline for Milestone 1 foundation work. Do not alter requirements without explicit product approval.

## Product intent

EruoNet Cloud is a cloud SaaS platform for multi-vendor network, ISP, CCTV, VoIP, fiber, wireless, and infrastructure simulation.

## Required future domains

- Web user experience.
- API surface.
- Control Center for operations and administration.
- Simulator service boundary.
- Simulation core.
- Device SDK.
- Topology engine.
- Protocol engine.
- Geospatial engine.
- CCTV engine.
- VoIP engine.
- ISP engine.
- Billing.
- Identity.
- Shared packages.

## Milestone 1 scope

Milestone 1 is limited to engineering foundation: repository structure, documentation, CI, Docker development configuration, validation tooling, and baseline security controls.

## Explicitly deferred capabilities

The following capabilities are not implemented in Milestone 1:

- Authentication functionality.
- Payment processing.
- Subscriptions.
- Network simulation functionality.
- Device emulation.
- CCTV simulation.
- IP PBX simulation.
- ISP simulation.
- GUI topology editor.
- Production deployment.
- AI fraud analysis.
